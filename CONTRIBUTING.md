# Contributing to MIR MEDIA LABS

Thanks for helping! Bug reports, ideas and pull requests are all welcome.

- **Bugs:** open a GitHub issue (Bug report template), or use **About > Report a bug** in the app.
- **Ideas / feedback:** open a Feature request issue, or use **About > Send feedback** (emails mirmedialabs@gmail.com).
- **Security issues:** see [SECURITY.md](SECURITY.md). Do not open a public issue.

## Pull requests
1. Fork, create a branch, and keep each change focused.
2. The web UI (`server/static/index.html`) and the Android app (`app/`) must stay in sync feature-wise.
3. Use MIR ICONS only, never emoji, in the UI.
4. Never commit keys, tokens, personal paths or IP addresses.
