Build an animated series

Pick a format and a look → build your cast → write an original song → the song is cut into shots that are lip-synced to it and flow from one to the next → one finished musical episode, ready for the editor.

Style bible

Attach 3–8 frames from shows you love. The writer works out why the look appeals to kids and writes one style prompt (it never names existing shows). Every picture in this series uses it.

Lineup

Cars, planes, boats, animals, trees, houses, toys… anything that isn't a cast member. Each one is drawn in the series style, with a turnaround and a detail sheet, and can be picked per episode so it looks the same in every shot.
