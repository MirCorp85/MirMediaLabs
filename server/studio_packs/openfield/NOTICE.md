# OpenField pack for MIR MEDIA LABS Studio

Apps and ComfyUI workflows ported from https://github.com/wexloops/openfield (MIT).
Full license text: LICENSE-OpenField. Model weights keep their own licenses (LTX-2.x Community License, TRELLIS.2 MIT, DINOv3 license, Gemma terms); each app's How it works tab lists them.

Loaded by server/freefield.py next to the freefield download (EXTRA_APP_DIRS), so updating either never clashes.
